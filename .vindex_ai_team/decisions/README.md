# decisions/

This is where filled-out instances of `templates/*.md` get filed — the actual
`ARCHITECTURE_DECISION.md`, `PRODUCT_SPECIFICATION.md`, etc. for a real feature or change, as
opposed to the blank templates in `../templates/`.

**Naming convention:** `YYYY-MM-DD_short-feature-name_ARTIFACT-TYPE.md`, e.g.
`2026-08-15_matter-conflict-screen_SECURITY_REVIEW.md`. Chronological, greppable, and self-
describing without opening the file.

**This directory starts empty.** The first real feature run through
`../workflows/new_feature_workflow.md` should produce its first inhabitants — see
`../README.md`'s worked example for what that looks like end to end.
