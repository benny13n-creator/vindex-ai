# WHY THE FILE STAYS
# It is the guard's allowlist. Keeping it (empty) documents the rule and gives
# a future offender somewhere to be recorded deliberately rather than by
# switching the guard off. tests/test_network_offenders_baseline.py pins the
# maximum at 0, so adding a line here fails the suite until someone raises that
# number on purpose, with an argument.
#
# What it costs while a name sits on this list: a real billed request on every
# CI run and every local run, against whichever key is in the environment, plus
# a nondeterministic result whenever the assertion touches model output. Two of
# the fixed tests were worse than billed -- they ran the production Pinecone
# tmp_* namespace cleanup, which DELETES data.
#
# WHAT THE 53 TURNED OUT TO BE
#   * ask_agent tests that mocked retrieve_documents but not the sudska-praksa
#     and mišljenja side pipelines, which embed the question before the path
#     under test is reached.

#     but not _get_client, leaving the query-decomposition, HyDE, GPT-expansion,
#     GPT-rerank and CRAG calls live.
#   * A handful of endpoint tests whose mock never took effect at all (see
#     test_doc_pitanje_api.py::test_pitanje_happy_path) or that reached Pinecone
#     through an ownership/cleanup path nobody had noticed.
